<h2>Getting Started</h2>
<ol>
    <li>Install <a href="https://nodejs.org/en/download">Node.js</a></li>
    <li>Click Code->"Download ZIP" - unzip</li>
    <li>Open the command line in the bare-rpg-main folder</li>
    <li>Run <code>npm install</code> + <code>npm run dev</code></li>
    <li>Ctrl-click the localhost URL shown in the command line.</li>
</ol>
<br>
<h2>Features:</h2>
<ul>
    <li>Player movement - touch + keyboard</li>
    <li>Levels - connecting them using editor components</li>
    <li>Arcade physics</li>
    <li>Hitboxes</li>
    <li>Enemy AI behaviour</li>
    <li>Preloading levels</li>
    <li>Base entity inheritance</li>
    <li>Custom component methods</li>
    <li>Customizing enemies with components</li>
    <li>BaseClass usage - weapon</li>
    <li>Static resolution - scaled up to fit</li>
</ul>
